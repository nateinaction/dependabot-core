## `dependabot-wordpress`

Wordpress support for [`dependabot-core`][core-repo].

### Running locally

1. Start a development shell

  ```
  $ bin/docker-dev-shell wordpress
  ```

2. Run tests
  ```
  [dependabot-core-dev] ~ $ cd wordpress && rspec
  ```

[core-repo]: https://github.com/dependabot/dependabot-core
